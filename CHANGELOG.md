# Changelog

## 0.3.2

- Promote the tested 0.3.2 beta to a stable release after successful Windows use.
- Remove the beta suffix from the helper title and EXE filename.

## 0.3.2-beta.1

- Keep sign-in clickable to reopen a prematurely closed browser login page.
- Default push-to-talk selection to Local.
- Encrypt login using Windows DPAPI and restore it when the helper reopens.

## 0.3.1-beta.1

- Select the first online host after Discord login; preserve an online selection on refresh.
- Add space and a destination label above Off / Squad / Local.
- Include a Discord icon inside the sign-in button.

## 0.3.0-beta.1

- Replace pairing-code entry with browser-based Discord login.
- Choose an account-owned host with remote control enabled.
- Show a top update banner for newer stable or beta GitHub releases.

## 0.2.4-beta.1

- Include the helper version in Windows EXE filenames for local and GitHub builds.

## 0.2.3-beta.1

- Show the helper version in the window title bar.

## 0.2.2-beta.1

Initial tracked source release.

- Windows GUI with dark theme and persistent connection status.
- Pairing with Giro's Discord Soundboard.
- Configurable Squad and Local push-to-talk keys.
- Releases held keys on playback stop, disconnect, and normal exit.
- Single-file Windows EXE build script.

Windows EXE build and game behavior require testing on Windows.
